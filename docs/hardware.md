## 接线

### TB6612 ↔ STM32MP157(M4 侧引脚,按 CubeMX 分配)
| TB6612 | 接到 | 说明 |
|--------|------|------|
| VM | 电机电源正(6~12V) | 电机供电 |
| VCC | 3.3V | 逻辑供电 |
| GND | 板 GND + 电源 GND | **共地** |
| PWMA | M4 定时器 PWM 输出 | 调速 |
| AIN1 / AIN2 | M4 两个 GPIO | 方向 |
| AO1 / AO2 | 电机两根电枢线 | 电机输出 |
| STBY | 3.3V | 使能 |

### 编码器 ↔ STM32MP157(定时器编码器模式)
| 编码器 | 接到 | 说明 |
|--------|------|------|
| VCC / GND | 3.3V / GND | 供电 |
| A 相 / B 相 | 定时器 CH1 / CH2(编码器模式) | 硬件 x4 解码 |

### (可选)MPU-6050 ↔ I2C
参见 `xiangmu` 仓库的 IIO 驱动文档;INT 接一路 GPIO。

## 安全注意
- 电机与逻辑**独立供电、务必共地**,否则方向/PWM 逻辑不稳。
- 首次上电将目标转速给 0、占空比限幅,确认方向正确再加速。
- 堵转保护由 M4 固件实现(高占空比 + 近零转速 → 停机)。

> 引脚具体分配随你的 CubeMX 工程而定,本仓库固件用 TODO 注释标出需要填入的 HAL 句柄。
